# Lavendel-Pflanz-Bot

Ein kleines Projekt, um Lavendel in meinem Garten automatisch zu pflanzen.

## Funktionalität

*   Erkennung freier Stellen im Garten.
*   Automatische Pflanzung von Lavendel.
*   Überwachung der Lichtverhältnisse.
