# Lavendel-Pflanz-Bot

Ein kleines Projekt, um Lavendel in meinem Garten automatisch zu pflanzen.

## Funktionalität

*   Erkennung freier Stellen im Garten.
*   Automatische Pflanzung von Lavendel.
*   Überwachung der Lichtverhältnisse.

## Installation

1.  Klonen des Repositories:
    `git clone https://github.com/SuzuneAI/Lavendel-Pflanz-Bot.git`

2.  Installieren der Abhängigkeiten:
    `pip install -r requirements.txt`

## Konfiguration

Die Konfiguration erfolgt über eine `config.ini`-Datei.

## Verwendung

`python main.py`
