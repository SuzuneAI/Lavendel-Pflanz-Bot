# Lavendel-Pflanz-Bot

Ein kleines Programm, das automatisch Lavendel in meinem Garten pflanzt.

## Installation

1. Stelle sicher, dass Python 3 installiert ist.
2. Klone das Repository.
3. Installiere die Abhängigkeiten mit `pip install -r requirements.txt`.

## Verwendung

`python main.py`

Die Konfiguration erfolgt über eine Konfigurationsdatei.
